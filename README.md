# 基于北斗时空数据的深远海养殖辅助分析终端软件 V1.0

## 简介

本软件是一款基于北斗卫星导航系统的深远海养殖辅助分析桌面终端软件，用于养殖环境监测、数据分析与设备控制。

## 功能模块

| 序号 | 模块名称 | 说明 |
|------|----------|------|
| 1 | 养殖池整体监控 | 实时监测各养殖池环境参数与鱼群健康状态 |
| 2 | 实时视频监控 | 养殖场视频监控实时画面与云台控制 |
| 3 | 病虫防治 | 病害检测、风险评估与处理措施跟踪 |
| 4 | 利润分析 | 各品种养殖成本、产出与利润率综合分析 |
| 5 | 标准值设定 | 水质参数标准范围与告警阈值配置 |
| 6 | 数据实时查询 | 传感器实时采集数据与北斗时空数据查询 |
| 7 | 趋势图查询 | 水质参数趋势分析与多维度数据对比 |
| 8 | 历史数据查询 | 历史水质监测数据查询与导出 |
| 9 | 控制形式设置 | 养殖设备控制模式配置与运行状态管理 |
| 10 | 控制时间设置 | 设备定时任务计划与执行周期管理 |

## 技术栈

- **语言**: C# (.NET Framework 4.x)
- **UI框架**: Windows Forms
- **编译器**: Windows 自带 `csc.exe`
- **依赖**: 仅 System.Windows.Forms / System.Drawing / System.Data，无外部依赖

## 项目结构

```
├── Program.cs          # 程序入口
├── MainForm.cs         # 主界面及10个业务模块界面
├── AppTheme.cs         # 主题配色方案
├── DemoData.cs         # 演示业务数据
├── build.ps1           # 编译脚本
├── README.md           # 本文件
├── bin/                # 编译输出目录
│   └── DeepSeaAquacultureTerminal.exe
└── .ai/                # 任务文件
```

## 编译与运行

### 编译

```powershell
.\build.ps1
```

### 运行

```powershell
.\bin\DeepSeaAquacultureTerminal.exe
```

或双击 `bin\DeepSeaAquacultureTerminal.exe`。

## 运行环境

- Windows 10 / Windows 11
- .NET Framework 4.x（Windows 系统自带，无需额外安装）
- 推荐分辨率：1440×900 或更高

## 界面说明

- **顶部栏**: 软件标题、北斗授时时间、系统状态
- **左侧导航**: 10个功能模块切换按钮
- **主内容区**: 当前选中模块的数据展示区
- **右侧面板**: 当前模块的详情信息或辅助操作
