# 验收标准

## 功能验收

- [ ] 程序可编译生成 `.exe`。
- [ ] 程序启动后显示软件名称：`基于北斗时空数据的深远海养殖辅助分析终端软件 V1.0`。
- [ ] 左侧导航包含 10 个业务模块。
- [ ] 每个业务模块点击后主界面内容切换。
- [ ] 页面中体现北斗时空数据、深远海养殖、监控、分析、控制、历史追溯等业务内容。
- [ ] 界面不是 Web 后台风格，而是 Windows 桌面终端软件风格。
- [ ] 界面视觉足够用于说明书截图。

## 代码验收

- [ ] 不依赖外部 NuGet 包。
- [ ] 可使用 Windows 自带 `csc.exe` 编译。
- [ ] 代码结构清晰，入口、主题、数据、界面分离。
- [ ] 不包含乱码。
- [ ] 不包含无关模板文字。

## 截图验收

- [ ] 1366x768 下界面不严重遮挡。
- [ ] 1440x900 下界面信息完整。
- [ ] 截图中能看清模块标题、字段、状态和关键按钮。
- [ ] 至少可生成 6 张用于软著说明书的截图。

## 后续文档验收

- [ ] 若插入 `软著补正2-v2` 说明书，每张截图下方应标注对应 C# 文件。
- [ ] 说明书截图与源程序模块命名一致。
- [ ] 不引入 Vue、HTML、Web 后台等与 C# 终端软件冲突的表达。
